## What code 78 means

If you take the driving test in a car with an automatic gearbox, your licence gets the condition **code 78**. The code means you may only drive vehicles with automatic transmission [[src:tv-theory-b]].

::: law kkl 3:7a
> Krav på innehav av körkortstillstånd gäller inte vid ett körprov, om sökanden redan har ett körkort med behörighet som utan något medicinskt skäl har villkorats till att avse automatväxlat fordon och körprovet ska ske med ett manuellt växlat fordon för vilket samma behörighet krävs.

**In English:** "A learner's permit is not required for a driving test if the applicant already has a licence whose category has been made conditional on an automatic vehicle, without any medical reason, and the driving test is to be taken in a manually geared vehicle that needs the same category."
:::

The rule above is about removing the code later. The code itself is printed on the back of the licence card, in field 12, where conditions and restrictions are written in coded form [[src:ts-card]]. Older licences can show the condition as **A.** instead of 78 [[src:ts-b]].

## What counts as an automatic car

Transportstyrelsen describes it as a vehicle with an automatic gearbox **without a clutch pedal** [[src:ts-faq]]. In practice that includes:

- cars with a traditional automatic gearbox (selector with P, R, N, D),
- cars with an automated or dual-clutch gearbox that has no clutch pedal, and
- most electric cars, which have no clutch pedal and no gears for the driver to change.

::: tip Why many learners choose automatic
There is no clutch to learn and no gears to choose, so you can spend more of your practice on traffic, speed and observation. The trade-off is that you cannot drive a manual car until you remove the code.
:::

## The theory test is the same

There is only one theory test for category B. Everything in the theory test applies to both manual and automatic drivers, and questions about manual gearboxes can appear [[src:tv-theory-b]]. Read [[lesson:automatic-gearbox]] for your own car, and it is worth knowing the basics of a manual gearbox too.

## Practising in both kinds of car

You may practise in both automatic and manual cars, unless your learner's permit has a condition that limits you to automatic cars (code 10.02). If you practise privately in a **manual** car, your supervisor may not have code 78 on their own licence [[src:ts-faq]].

## Removing code 78 later

To drive manual cars, you take a **new driving test in a manual car** [[src:tv-theory-b]]. Here is what applies:

::: steps
1. **No new learner's permit** is needed, as long as the automatic condition was not set for medical reasons [[src:kkl|3:7a]].
2. **No new risk education** is needed for this test [[src:kkl|3:4b]].
3. **Practise privately only with an approved supervisor**, who must not have code 78, or practise at a driving school [[src:ts-practice]].
4. **Have a new photo taken** at Trafikverket before the test [[src:tv-before]].
5. **Pass the driving test** in a manual car. There is no new theory test.
:::

::: note Coming change in EU rules
The EU's fourth driving licence directive will also allow the automatic condition to be removed after special training in a manual vehicle, instead of a new test. Most of the directive applies from 26 November 2029, and when this site was checked ([[fact:checkedOn]]) Sweden had not decided whether to introduce this training [[src:ts-future]].
:::

::: warning
Driving a manual car when your licence has code 78 breaks the condition on your licence. That is a crime punished with a fine [[src:tbl|3]].
:::

## Code 78 and other categories

If you already have, or have had, a B licence for manual cars, you may take the driving test for B96 or BE (or heavier categories) in an automatic vehicle **without** getting code 78 [[src:ts-practice]].
